# Demo Scenarios

This directory contains step-by-step demonstrations for Playwright CLI and
Playwright Test Agents. Run commands from the repository root and confirm each
result before continuing.

- [Attach to an authenticated local Chrome session](attach-authenticated-local-chrome/README.md)
- [Automate a manual test procedure](automate-manual-testing/README.md)
- [Create a screenshot guide with Playwright CLI](create-screenshot-guide/README.md)
- [Build and heal tests with Playwright Test Agents](playwright-test-agents/README.md)
- [Watch Playwright releases with an agentic workflow](playwright-release-watch/README.md)
